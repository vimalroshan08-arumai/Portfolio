# Portfolio

A static portfolio site for Vimal Roshan G.

## Deploy

This project is ready to deploy as a static site on any host that serves files from the repository root, such as GitHub Pages, Netlify, or Vercel.

### Requirements

- Keep `index.html` at the project root
- Ensure `profile-photo.png` remains in the same folder
- No build step is required

### Example

For GitHub Pages, publish the repository root directly from the `main` branch.

For local preview:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in a browser.
